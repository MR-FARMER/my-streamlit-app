# my-streamlit-app
an online app about python method searching

https://my-app-app-8atgkuabjmh236idwtb7hi.streamlit.app/
through the website upon, you can go straight for searching the python tools

A Python tool search engine: just enter the keywords of the program result you want to achieve, and it will find the related Python tools. For example, if I need to do case conversion, I just search for 'uppercase' and get the corresponding Python tools. It's mainly for beginners, the English mode is updating. 

一个python工具搜索引擎，输入想要达成的程序结果关键词即可搜出相关的python工具，例如我需要大小写转换，就搜索“大写”，即可获得相应python工具，主要给新手小白使用，后续将会更新英文模块。
